# うちの子尻尾ふりふり掛け時計

うちの子の尻尾がふりふり動く、デスクトップ用の振り子時計です。
キャラクターが抱えた文字盤で時刻を表示し、尻尾の揺れ幅や速さを好みに合わせて調整できます。

## ダウンロード

**[最新版をダウンロード](https://github.com/hyt-teto/shippo-furifuri-clock/releases/latest)**

現在配布しているのは **Windows 64bit（x64）版**です。macOS版は準備中で、まだ配布していません。

Releaseの「Assets」から、名前が **`-setup.exe`** で終わるインストーラーをダウンロードしてください。
`latest.json`と`.sig`は自動更新用のファイルで、手動で開く必要はありません。

## 主な機能

- キャラクターのイラストに針を重ねたアナログ時計
- 尻尾が左右に揺れる振り子アニメーション
- 尻尾の揺れ幅を3〜18°、動く速さを0.25〜3倍で調整（初期値は10°・1倍）
- テト・スイカ・あけび・詭云のキャラクターを同梱
- 時計だけを表示する背景透過モード
- 縦横比を保った透過ウインドウの拡大・縮小
- コンパクト表示・常に手前に表示
- キャラクター画像フォルダの追加
- ログイン時の自動起動、設定とウインドウ位置・サイズの保存
- バックグラウンドでの自動アップデート

## インストール

1. [最新版のRelease](https://github.com/hyt-teto/shippo-furifuri-clock/releases/latest)を開きます。
2. `-setup.exe`で終わるインストーラーをダウンロードして実行します。
3. インストーラーの案内に沿って導入し、「うちの子尻尾ふりふり掛け時計」を起動します。

ユーザー専用のインストール方式です。管理者として実行する必要はありませんが、Windowsの安全確認や端末の管理ポリシーによって確認画面が出る場合があります。

配布ファイルには**自動更新を検証するための署名**を付けています。ただし、**Windowsの発行元を認証するコード署名はまだ付いていません**。この2つは別の仕組みです。安全確認の表示が出た際は、内容を確認してください。

## 使い方

設定欄の「キャラクター」で表示する子を選び、「尻尾」で動きのオン・オフ、揺れ幅、速さを変更できます。速さの1倍は1往復に2秒、2倍は1秒、0.5倍は4秒です。

上部の表示ボタンから「常に手前に表示」「コンパクト表示」「時計のみ・背景透過」を切り替えられます。小さいウインドウでは「時計の設定」ボタンから設定を開いてください。

透過モードでは時計をドラッグして移動できます。時計にマウスを重ねると操作ボタンが現れ、設定の変更や通常表示への切り替えができます。`Esc`キーでも通常表示に戻れます。

## 設定の保存と自動起動

キャラクター、尻尾の設定、表示モード、最前面表示、ウインドウの位置・サイズは自動保存し、次の起動時に復元します。モニター構成が変わった場合は、時計が画面外に隠れないよう位置を補正します。

「ログイン時に起動」をオンにすると、PCの起動・再起動後、Windowsにログインしたタイミングで時計も起動します。自動起動を利用する場合は、インストーラーで導入したアプリを使用してください。

## 自動アップデート

「自動アップデート」がオンの場合、起動後と24時間ごとに新しい版を確認します。更新ファイルの署名を検証してから、インストーラーの進捗画面を出さずに更新し、時計を再起動します。更新前に設定とウインドウ位置を保存します。

自動更新は設定でオフにできます。「更新して再起動」ボタンから手動で確認することもできます。通信に失敗した場合は、設定欄に状態を表示します。

初回はインストーラーからの導入が必要です。開発版や、インストールせず単体で起動した実行ファイルでは、自動更新は行いません。OSの安全確認を無効化する仕組みではありません。

## キャラクターの追加

次のような画像フォルダを用意し、設定の「画像フォルダを追加」ボタンから選択します。

```text
キャラクター名/
  body.png
  tail.png
  config.json
```

フォルダ名がキャラクターの名前になります。`body.png`は必須で、`tail.png`と`config.json`は任意です。尻尾の画像がない場合は振り子を表示しません。

`config.json`では、文字盤の中心や大きさ、尻尾の位置・回転軸などを指定できます。省略時はテトと同じ配置になります。形の異なる画像では、その画像に合わせた設定が必要です。

追加した画像はアプリ専用のデータフォルダへコピーされるため、元のフォルダを移動しても使えます。同じ名前のセットを追加し直すと、そのセットを更新します。
